# Sektor przykładowy: Atlas Zgłoszeń

Ten sektor jest fikcyjnym, publicznym przykładem organizacji wiedzy w stylu Obsidian. Nie jest repozytorium produkcyjnym, nie zawiera danych wejściowych ani nie przyznaje dostępu.

Czytaj w kolejności: [`INDEX.md`](INDEX.md) → Cel → Teza i Antyteza → Synteza → ADR → Ewaluacja. Sześć katalogów zachowuje układ warsztatu: `00-Cele`, `10-Tezy`, `15-Antytezy`, `20-Decyzje`, `25-Syntezy`, `90-Ewaluacja`.

**Status przykładu:** szkic. Miary opisują hipotetyczny test na 16 syntetycznych kartach; żaden wynik nie został wykonany ani ogłoszony jako produkcyjny.
